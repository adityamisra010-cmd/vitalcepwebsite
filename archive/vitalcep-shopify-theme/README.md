# Archived: Vitalcep Shopify theme

These files are the **old Vitalcep Shopify store theme** (Liquid sections + CSS).
They predate the Agency OS app and are **not used by it** in any way — Agency OS
is a Next.js application and never loads these.

They were moved here out of the repo root so the project reads cleanly as the
generic, multi-client **Agency OS** tool. Kept (rather than deleted) in case the
Vitalcep storefront theme is still needed.

Safe to delete entirely if you no longer need the Shopify theme.
